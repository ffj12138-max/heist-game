Midnight Vault is a top-down 2D stealth heist game: cross a museum gallery, time the laser hall, crack the vault to steal the Star of Meridia, and escape to the getaway van while guards, cameras and the alarm meter work against you.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
